# Code signing (kill the Gatekeeper / SmartScreen warnings)

The release builds are currently **unsigned**, so macOS shows "unidentified
developer" and Windows shows SmartScreen. Fixing that needs **real certificates
tied to your identity** — those can't be generated by tooling, you have to
enroll. This doc is the exact path. The CI is already wired and **gated**, so
nothing breaks until you turn signing on.

> Security note: the steps below involve your Apple ID and a certificate. **You**
> run the `gh secret set` commands — don't paste these secrets into chat.

---

## macOS — Developer ID + notarization

### 1. Enroll (you)
Join the **Apple Developer Program** ($99/yr): <https://developer.apple.com/programs/>.
Note your **Team ID** (Membership page, e.g. `AB12CD34EF`).

### 2. Create the Developer ID Application certificate
1. **Keychain Access → Certificate Assistant → Request a Certificate From a
   Certificate Authority** → enter your email, "Saved to disk" → save `CertificateSigningRequest.certSigningRequest`.
2. <https://developer.apple.com/account/resources/certificates/list> → **+** →
   **Developer ID Application** → upload the CSR → **Download** the `.cer`.
3. Double-click the `.cer` to install it into your **login** keychain.

### 3. Export it for CI
```sh
# find the identity string (copy the full "Developer ID Application: …(TEAMID)")
security find-identity -v -p codesigning

# In Keychain Access: find "Developer ID Application: …", right-click → Export →
# save as cert.p12, set an export password. Then base64 it:
base64 -i cert.p12 -o cert.p12.b64
```

### 4. Notarization credential
<https://appleid.apple.com> → **Sign-In and Security → App-Specific Passwords** →
generate one (e.g. "crab-control-notarize").

### 5. Set the GitHub secrets (you run these)
```sh
gh secret set APPLE_CERTIFICATE            < cert.p12.b64
gh secret set APPLE_CERTIFICATE_PASSWORD   --body '<the .p12 export password>'
gh secret set APPLE_SIGNING_IDENTITY       --body 'Developer ID Application: Your Name (TEAMID)'
gh secret set APPLE_ID                     --body '<your Apple ID email>'
gh secret set APPLE_PASSWORD               --body '<the app-specific password>'
gh secret set APPLE_TEAM_ID                --body '<your Team ID>'
gh variable set SIGN_MACOS                 --body 'true'   # flips signing on
```

### 6. Release
Tag a new version (`git tag v0.1.3 && git push origin v0.1.3`). The macOS job
will sign + notarize automatically. Verify on the built app:
```sh
spctl -a -vvv "Crab Control.app"     # should say: accepted, source=Notarized Developer ID
codesign -dv --verbose=4 "Crab Control.app"
```

## Windows — Azure Trusted Signing (recommended)

Traditional OV/EV certs are expensive and EV needs a hardware token (awkward in
CI). **Azure Trusted Signing** (~$10/mo) is the CI-friendly option.

### 1. Set up (you)
1. Azure subscription → create a **Trusted Signing account** + a **Certificate
   Profile** (requires identity/org verification). Docs:
   <https://learn.microsoft.com/azure/trusted-signing/>.
2. Create a service principal with the **Trusted Signing Certificate Profile
   Signer** role. Capture: tenant id, client id, client secret, the **endpoint**
   (region URL), **account name**, **profile name**.

### 2. Set secrets / variables
```sh
gh secret set AZURE_TENANT_ID        --body '<…>'
gh secret set AZURE_CLIENT_ID        --body '<…>'
gh secret set AZURE_CLIENT_SECRET    --body '<…>'
gh secret set AZURE_TS_ENDPOINT      --body 'https://<region>.codesigning.azure.net/'
gh secret set AZURE_TS_ACCOUNT       --body '<account name>'
gh secret set AZURE_TS_PROFILE       --body '<profile name>'
gh variable set SIGN_WINDOWS         --body 'true'
```

### 3. Wiring
Windows signing happens **during** bundling via Tauri's `bundle.windows.signCommand`
(so the `.msi`/`.exe` are signed before upload). This needs the Trusted Signing
client installed on the Windows runner and a small `signCommand` in
`tauri.conf.json`. **Ping me once the Azure side exists** — I'll add the runner
setup step + `signCommand` and verify with:
```sh
signtool verify /pa "Crab Control_x.y.z_x64-setup.exe"
```
